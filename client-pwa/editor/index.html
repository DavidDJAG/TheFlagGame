Instructions

  • Perimeter / Polygon: click to add vertices. Close the shape with the first point, Enter, or the Close shape button.
  • Rectangle / Circle: click and drag.
  • Flag: click to place it. Change the team in the dropdown.
  • Selection: click an object to move it. If it is selected and is not a circle, drag its points for precise editing.
  • Pan: in selection mode, use Ctrl + drag to move around the map while zoomed in.
  • Zoom: use the buttons, +, -, 0, or the mouse wheel over the map. Zoom stays centered on the current cursor position.
  • JSON: save the map and reload it whenever you want.
  • Server: use Load from server to fetch GET /api/map and Save to server to send PUT /api/map.
